# Aeterna Linux

Aeterna Linux is an independent Linux distribution built from source.

## Current Development Target

Aeterna is currently being developed for private/internal use.

### Year 1

- Linux kernel 7.2.8
- x86_64
- UEFI
- GRUB
- glibc
- GCC
- dpkg
- APT
- Kali Rolling repository
- QEMU-based testing

### Future

Before public release, Aeterna will transition to its own package
repository while retaining APT/dpkg as the package management system.
